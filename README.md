# 嘉立创扩展 · JLC Extensions

LIYAN 开发的嘉立创 EDA 专业版扩展。每个扩展独立维护源码、版本和安装包；本仓库只作导航。

| 扩展 | 功能 | GitHub 源码 |
| --- | --- | --- |
| 器件交换 | 交换器件位置、方向、板层，可同步位号丝印及对应引脚连接的走线网络 | [component-swap](https://github.com/ly12121/component-swap) |
| PCB网络刷色 | 点选网络刷色，保存和切换多套配色，自动应用同名网络，240 色色板 | [pcb-net-color](https://github.com/ly12121/pcb-net-color) |

## 下载与安装

- [器件交换安装包](https://github.com/ly12121/component-swap/tree/main/release)
- [PCB网络刷色安装包](https://github.com/ly12121/pcb-net-color/tree/main/release)

下载 `.eext` 后在嘉立创 EDA 专业版的扩展管理器中导入。更新前建议备份 PCB 和扩展配置，器件交换后检查 DRC。
